Container Management API for podman containers.

A project sprung out of the urge to learn rust and wanting to build a API for managing podman containers in my local environment.

All requests and responses are JSON based for all API endpoints.

All interfaces related to systemwide information and configuration for podman resides under here.

/v1/containers/create

API for creating a container.

All options needs to be separated with a comma (,) and start with -- or they will be invalid.

For example like this:

{
  "name": "MyContainer",
  "image": "/full/path/to/repo/image:tag",
  "options": "--option1,--option2=value2"
}
Authorizations:
basicAuth

/v1/pods/setstate

With this API you can start, stop, pause and so on for a single pod.

Valid states to user are: start, stop, pause, unpause & restart

This will affect all containers connected to the pod you are issuing the command to, so if only one container in the pod needs to be for example restarted and it do not have dependencies from other containers, sometimes it is better to just restart that single container.

Authorizations:
basicAuth
Request Body schema: application/json
name
string
state
string
